Если возникает ошибка  можно попробовать через net stop winnat
Error response from daemon: ports are not available: exposing port TCP 0.0.0.0:8223 -> 127.0.0.1:0: /forwards/expose returned unexpected status: 500

net stop winnat — это команда командной строки Windows (требует прав администратора), которая принудительно останавливает службу драйвера NAT (Network Address Translation). Она используется для решения конфликтов портов, когда игры, Docker или другие приложения не могут запуститься, так как порт занят системой.

Потом запустить команду
net start winnat

Список команд для ПЕРЕСОЗДАНИЯ КОНТЕЙНЕРОВ
# 1. Остановить все контейнеры
docker compose down

# 2. Удалить volumes (данные БД/логи потеряются!)
docker compose down -v

# 3. Очистить образы (опционально, пересоберёт Dockerfile)
docker compose build --no-cache

# 4. Запуск с нуля
docker compose up -d

# 5. Проверка статусов
docker compose ps

# 6. Логи инициализации (первый запуск ~5 мин)
docker compose logs -f airflow-init
